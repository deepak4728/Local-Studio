The MVP · Six product building blocks

AI and ordering designed around the organization.

Keep everyday work fast and local. Use carefully structured models and network options for the tasks that need them.

01 · LOCAL INFERENCE

Fast reasoning on-device

Run Qwen 3.5 4B locally for routine questions, basic reasoning, and analytics, keeping common work responsive and cost-efficient.

02 · FRONTIER ROUTING

Cloud models for heavier jobs

Connect provider APIs for high-complexity or scheduled tasks, so larger model calls are used where they add value.

03 · SYSTEM 1

Say it once; classify the input

Accept a voice command or a single-box message, map its values to the form schema, and attach a confidence probability to each field.

04 · SYSTEM 2

Create with strict schemas

Use a stronger structured workflow for organization and form creation, producing schema-following output that can be reviewed before use.

05 · ORGANIZATION DEPLOYMENT

Run on the organization’s network

Deploy for each organization over its Wi-Fi. Keep ordering on the local network during internet outages, or expose the service publicly through configured port forwarding.

06 · QR + BARCODE

Scan into a simpler order

Use QR codes and barcodes to connect guests to menus, items, or tables with less manual entry and more attention on the cafe experience.

AI architecture · Local first, schema guided
Use the smallest model that fits the task.
Keep routine inference on the organization’s device and reserve provider APIs for the work that benefits from a frontier model.

    
Two inference paths
Fast capture, careful creation.
System 1 classifies a short voice or text input against a known form schema and returns a confidence score for each field. System 2 handles organization and form creation with strict structured output.
On-deviceQwen 3.5 4B for everyday reasoning and analytics.
Provider APIsScheduled or high-complexity model tasks.
Schema checksReview structured output before publishing.
Organization control
Keep ordering close to the team.
Organization deployments can serve guests over local Wi-Fi, with public access available through configured port forwarding. The local ordering path can continue when internet access is unavailable.
Voice or text → schema classification + field confidence
Form or organization setup → strict structured output
Guest order → QR/barcode → organization network

  


  
Help center · Frequently asked questions
A few useful details.
Learn how organizations, forms, and submissions fit together.

    

      
Can someone fill out a form without an account?
Yes. A published form can be shared with anyone who has its link. Organization membership stays private, and public respondents only see the form and submit their response.

      
How are organizations kept separate?
Organization pages and records check the signed-in account’s membership. A person in one organization does not get access to another organization’s forms, documents, or chat history.

      
Can I edit a form after creating it?
Yes. Admins and managers can edit organization forms. AI suggestions are a starting point, and you can adjust fields and validation before publishing.

      
Can I export submissions?
Submission exports are available from the organization’s submissions area. The button above exports sample data only, so you can preview the CSV format.

      
How are local and cloud models used?
Qwen 3.5 4B handles routine inference on-device. Configured provider APIs are reserved for higher-complexity or scheduled work, while schema checks keep generated forms and organization setup structured.

      
Can orders work when internet access is down?
When the organization deployment and guest device share its Wi-Fi, the local ordering flow can remain available without an internet connection. Public access can be enabled separately through configured port forwarding.
